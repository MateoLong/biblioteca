# The code lives in a public GitHub repo so it can be hosted free on GitHub Pages

The owner chose to stay on the free plan (2026-10-04), and free GitHub Pages needs a public repo. Making the repo private would unpublish the site and could break her installed app on its next online start. Nothing personal is ever committed: her data exists only on her iPad, and the Datos de ejemplo are invented.

## Considered Options

- GitHub Pro: private repo, same address.
- Cloudflare Pages or Netlify: private repo free, but a new address, and she would have to move her data with a backup.
