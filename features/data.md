# Datos de ejemplo, copias y planillas
Path: first run → "Probar con datos de ejemplo"; Ajustes → Borrar datos de ejemplo; Ajustes → Guardar copia de seguridad / Recuperar una copia / Planillas.
End state: demo rows are flagged is_demo and clearing removes only them and their loans; the backup is a JSON file named biblioteca-copia-<fecha>.json, and restoring it on an empty iPad brings back every book, student and loan; Ajustes shows when the last copy was made and the counter reminds her after 7 days; CSV exports open in Excel (UTF-8 BOM, ';').
Device: data survives closing the app; once opened, the app opens without internet.
