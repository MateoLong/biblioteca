# Corregir y borrar
Clase: Clases → the class tab → "Editar 4°B" → type another name, Guardar → the class is renamed. If that name is a class that already exists, it asks "¿Juntar…?" and on "Sí, juntarlas" the two become one: a student in both (same name) becomes one with both histories. "Borrar 4°B" → "Sí, borrarla" → its students who never borrowed are deleted, those with history are archived. Refused while any of them still has a book.
Alumno / Libro / Ejemplar: "Borrar" shows only when it was never lent (a student who never borrowed, a book or copy never lent) → "Sí, borrarlo" → gone. Anything with history is archived (or dado de baja) instead.
Edge: every Borrar asks first in a yellow notice on the page and changes nothing until "Sí". After deleting a student or book she lands on its list.
Fucsia: a book whose Sección is No ficción and that has no age colour wears a fucsia forro on every screen; with an age colour it wears that.
